# UML Representation Strategy

UML is modeled as a format family with a tool-neutral semantic layer rather than a single file syntax. Concrete serializations or tools are adapters.

A UML Class Diagram and Mermaid `classDiagram` can share structural capabilities, but they are not interchangeable standards. The same abstract electronics-system profile may bind to either while declaring fidelity differences.

The UML seed includes structural and behavioural diagram types. Current capability lists are registry metadata, not a normative implementation of a specific UML specification revision.
