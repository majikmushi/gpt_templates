# Transformation Routing

Transforms form a directed graph. A route planner chooses a path using required semantic capabilities, profile compatibility, target/version compatibility, fidelity/loss declarations, reversibility, validator availability and deterministic/tooling requirements.

Preferred routes minimize semantic loss, not hop count.

## XSLT analogy

XSLT remains both an actual XML transform engine and an architectural reference: declarative matching, selection, construction, parameters and composition. Repository transforms generalize that idea by operating against canonical semantics and format profiles.
